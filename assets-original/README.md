# FROZEN USD — production logo master v1.1

Selected mark: the original THREE-PRONG forked S, with a central stub and two branches at each end.
This corrected package preserves the original three-prong forked-dollar geometry. It replaces the mistakenly supplied two-prong Y-dollar master. It contains no Y-dollar or snowflake artwork.

## Start here

Use **SVG/Frozen-USD-Master.svg** as the canonical logo. It is a resolution-independent vector with a cyan circular field and an ink symbol. The area outside the circle is transparent. Import the SVG into your brand-design application and preserve its proportions.

All artwork is native filled vector geometry. No fonts, linked images, live strokes, filters, masks or clipping paths are required. The symbol is one closed path. The circle remains a separate editable vector object. The 1024-unit canvas is a coordinate system, not a resolution limit.

All variants use the same 1024x1024 canvas and exact symbol path. The symbol-only assets retain the master's internal spacing. Scale the mark uniformly; do not stretch, thicken, rotate or reshape its ends. The symbol's height is 72% of the circular field diameter.

## Colors

- Glacial cyan: #79DAFF / RGB 121, 218, 255
- Ink: #071827 / RGB 7, 24, 39
- White: #FFFFFF
- Black: #000000

SVG and PNG assets use RGB color. For print, convert with the print provider's required color profile and proof the result; no universal CMYK or Pantone match is claimed.

## PNG exports

Each variant is provided at 2048, 1024, 512, 256, 128, 64, 48, 32, 24 and 16px. These are direct vector renders. Choose an export appropriate to the intended display size and pixel density rather than repeatedly resizing a small PNG. The white standalone symbol is intended for dark backgrounds.

The 16px and 24px files are supplied for completeness. Their fork detail is reduced at those sizes; 32px and larger is the preferred display size for preserving the detail. This is a known design limitation, not a missing vector-master issue.

## Scope

This is the final selected SYMBOL master package for building the full identity. A finalized wordmark, font system, lockups, clear-space rules and full brand guide remain separate brand-pack work. No placeholder wordmark is included.
